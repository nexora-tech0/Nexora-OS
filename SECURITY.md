# Security policy

Security is a project requirement, but this repository has no published
release, supported product version, security team, or verified private
reporting endpoint yet.

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Until a private
reporting channel is established, contact the project owner through a private
channel that you have independently verified. Do not send sensitive reports to
an unverified address or account. A verified security contact and response
process must be published before the project accepts public users or releases.

Include affected revision or component, impact, prerequisites, and safe
reproduction details. Avoid accessing data or systems beyond those you own or
are authorized to test. Do not include credentials or personal data in a
report.

## Current limitations

No security certification, formal audit, supported release, or guaranteed
response time is claimed. This policy must be updated with supported versions,
private contact information, and response targets before the first public
release.
