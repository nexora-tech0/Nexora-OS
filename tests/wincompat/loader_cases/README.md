# Host-side PE header fixtures

Run from the repository root with:

```powershell
python tests\wincompat\loader_cases\test_pe_fixtures.py
```

The script deterministically builds one minimal two-section AMD64 PE32+ byte fixture in memory,
then applies each named mutation and checks the expected status against a Python model of the
structural predicates in `ps\peimage.c`. No compiler, OS boot, ISO, disk, or changes to the
existing wincompat probe are required. The fixture bytes are generated by the test, not read from
external binaries.

Cases cover an accepted header layout and rejection of missing/wrong DOS and NT headers, an
invalid machine or executable flag, PE32 instead of PE32+, undersized optional headers, invalid
section counts/table bounds, bad section alignment, invalid image size/base/header size/entry
point, and section virtual/raw ranges outside their allowed bounds. There are 29 named cases.

**Scope:** these tests exercise only the Python structural-contract model and generated fixture
bytes. They do not call the production C validator or loader, inspect imports/relocations/TLS,
map or execute an image, or establish that a fixture runs under Nexora. OS behavior requires
separate testing through Nexora.
